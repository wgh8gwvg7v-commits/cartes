# La collection de Matthew

Collection One Piece (OP12) et liste de souhaits NBA, avec les prix en CHF.

- `index.html` : la page.
- `data/collection.json` : les cartes et l'historique des prix, mis à jour chaque matin.
- `img/` : les images des cartes.

Prix One Piece : cote Cardmarket (via Limitless TCG). Prix NBA : ventes eBay terminées (via SportsCardsPro).
